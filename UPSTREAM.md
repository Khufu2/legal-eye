# Legal Eye upstream register

Audit date: **2026-09-03 (UTC)**. This register is the incorporation gate for open-source software and content. A repository appearing here is not, by itself, approval to ship it. Exact refs are pinned for evaluation; production upgrades require licence re-check, compatibility tests, migration review, and a new entry in the architecture review log.

## Decision summary

| Capability owner | Decision | Integration boundary |
| --- | --- | --- |
| OpenContracts | Adopt | Dedicated service exposed through a Legal Eye adapter over REST/GraphQL/MCP. No upstream UI is shipped. |
| Docling family | Adopt | Private parsing service; canonical Docling JSON is retained with pages, coordinates, structure and provenance. |
| OpenAgreements | Selective adoption | Code may be called as a library/service; every content asset is separately gated by `template_license_registry`. |
| Indigo | Concepts and protocol first | Use Akoma Ntoso/FRBR concepts. GPL code may run only as a separately deployed service after counsel review. |
| PostgreSQL + pgvector | Adopt | System of record and retrieval substrate in the connected Supabase project. |
| LangGraph | Adopt narrowly | Durable, inspectable state machine for long-running legal workflows. |
| LlamaIndex / LangChain | Defer | No initial direct dependency. Reconsider only against a measured retrieval/orchestration gap. |

## Incorporation rules

1. No upstream source or content is copied without a row in this register and a machine-readable attribution record.
2. Content licensing is evaluated independently from code licensing.
3. GPL/LGPL components must have a documented distribution and linking analysis before any binary or package enters a production image.
4. Upstream interfaces are never exposed as Legal Eye’s product UI.
5. Forks require a named maintainer, patch budget, security-update path and exit plan. Service adapters are preferred.
6. Every upgrade reruns licence scanning, SBOM generation, vulnerability scanning, API contract tests and the relevant legal-document golden set.
