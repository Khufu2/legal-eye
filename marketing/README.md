# LOCKE marketing website

This is a separate static, zero-build public marketing site. It does not replace the live legal workspace or its authenticated routes.

## Deploy

Create a Vercel project linked to `Khufu2/legal-eye` with:
- Root directory: `marketing`
- Framework preset: Other / no framework
- No build command or dependencies
- Output directory: `.` or default static detection

The product remains at `https://www.lockeslaw.xyz/` until its dedicated app domain is assigned. Before switching the marketing site to the main domain, change the **Open app** URLs to the future verified app origin.

## Product claim controls

- Source evidence, review, drafting, matters and workflow descriptions reflect existing application architecture and UI, not a guarantee that every enterprise flow is certified or fully accepted.
- The screenshot-like UI is explicitly illustrative.
- Starter at TZS 49,000 is labelled **planned**; checkout, plan quotas and packages are not presented as live.
- There are no invented testimonials, customer logos or compliance certifications.
- Demo enquiries launch an email to hello@lockelaw.xyz; no form submission is implied.

## QA checklist

- Check desktop and mobile navigation, product tabs and keyboard navigation.
- Verify clickthrough links to app and demo email.
- Replace canonical URL after changing domains.
- Review pricing, product entitlements and security statements with product owner before public launch.
